# Atalhos

`Mod` representa `Ctrl` no Windows/Linux e `⌘` no macOS. Todos podem ser remapeados em **Configurações → Atalhos**.

## Navegação

| Ação | Atalho |
| --- | --- |
| Busca global | `Mod + K` |
| Abrir/entrar no quadro selecionado | `Mod + Enter` |
| Fechar aba | `Mod + W` |
| Próxima aba | `Mod + Tab` |
| Alternar barra lateral | `Mod + B` |
| Alternar inspector | `Mod + Shift + I` |
| Alternar tema | `Mod + Shift + L` |

| Novo código | `Shift + C` |
| Novo cartão | `C` |
| Nova tarefa | `T` |
| Novo checklist | `L` |
| Nova coluna | `Mod + Shift + K` |
| Novo quadro | `Mod + Shift + N` |
| Novo desenho Excalidraw | `D` |

## Formatação de texto

Valem enquanto o **texto avulso** está em edição (o mesmo formato que a barra flutuante e o inspector aplicam):

| Ação | Atalho |
| --- | --- |
| Negrito | `Mod + B` |
| Itálico | `Mod + I` |
| Sublinhado | `Mod + U` |
| Riscado | `Mod + Shift + X` |
| Aumentar fonte | `Mod + =` |
| Diminuir fonte | `Mod + -` |

Atalhos de uma letra são ignorados enquanto você digita em campos de texto. Combinações com `Mod` continuam ativas para desfazer, salvar e buscar.

> No navegador, alguns atalhos do sistema (como `Ctrl+W` e `Ctrl+Tab`) podem ser interceptados. No app Tauri eles funcionam normalmente.
