# Cofre de exemplo

Este cofre pequeno serve para testar a importação do Obsidian no EliasNote.

No EliasNote, abra **Arquivo (⋯) → Cofre do Obsidian** e selecione esta pasta
(`examples/obsidian-vault`). Você verá:

- um workspace novo com um quadro raiz;
- o quadro **Projeto**, com duas notas, um canvas e um desenho;
- a imagem `ideia.svg` importada como anexo local;
- wiki-links clicáveis entre as notas e referências bidirecionais.

O cofre original não é modificado.
